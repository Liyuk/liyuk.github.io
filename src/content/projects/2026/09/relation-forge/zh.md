有些关系让人不舒服，却又很难说清楚哪里不对。可能是对方提了一个你不愿意答应的要求，可能是一次争执之后，你一直在想自己是不是说重了。事情还在发生，要怎么回、要不要继续谈，心里都没个准数。

我希望 RelationForge 能在这种时候帮上忙。你可以把事情经过、有关的聊天和自己的疑问放进去，让它帮你看看：对方在要求什么，你又是怎么回应的。比如，你问投资平台能不能核实，对方却说“你连我都不信吗”。先把这一来一回看清楚，才知道接下来还有什么需要问。

我也希望它能用来看看自己。催同事交资料，原本是想把工作往前推；说出口的话却可能让对方只记住自己被当众贬低了。迟交的问题要处理，自己的表达也可以改，这两件事放在一起看才有用。

项目目前有两个 Skill，在 Codex 或 Claude Code 里使用：“人际深度解析”用来读个人介绍、聊天和自己的经历；“互动风险分析”更侧重索款、施压、威胁和疑似霸凌。安装说明在[后面](#install-relation-forge)，也可以直接看 [GitHub 仓库](https://github.com/Liyuk/relation-forge)。

## 五个场景，看它具体怎么回答

网恋索款、投资邀约和工作纠正这几类情形，我参考了文中链接的公开资料。下面贴出的答复保留了试答里的判断、依据和应对选择，你可以对照自己的问题看。

### 1. 我只是催进度，为什么对方觉得被羞辱？

**情境输入**：同事没按约定时间交来项目汇总需要的资料。提问者在有其他同事的项目群里写：“你每次都这样，根本不靠谱。”同事随后私信解释，提问者当天没有回复。第二天同事说觉得被公开羞辱；提问者当时认为自己是在维护进度，但现在想知道自己的表达和不回复造成了什么影响，怎样既要求交付又不把矛盾扩大。

**人际深度解析的答复**：

> 你的表达确实超出了交付提醒。“你每次都这样，根本不靠谱。”把一次已知的延误扩大为对整个人的评价，又发生在项目群里；同事第二天明确说感到被公开羞辱。你是想守住进度，但这并不能消除对方感受到的影响。你当天没有回复，也可能让对方觉得自己的解释没有被接受。不过，我们还不知道你为什么没回，不能据此认定你是在故意惩罚对方。
>
> 还需要弄清楚：资料为什么迟交、之前是否确实发生过类似情况、对方在私信里解释了什么，以及延误对项目造成了什么影响。可以先私下回复并道歉，承认在群里评价对方不妥，不要用“但你先迟交”来抵消歉意。也可以和对方商量，是否在原群里简短更正这句评价；不要公开对方的私信。
>
> 交付的事再单独说清楚：还缺哪些资料、会影响什么、什么时候补齐；如果遇到困难，应该什么时候提前说。以后需要暂停沟通时，说明会在何时回复。

### 2. 征友对象不谈婚育，是隐瞒还是节奏不同？

**情境输入**：一份征友简介写“喜欢徒步和做饭，希望认真发展一段关系”，没提收入、婚史或是否想要孩子。两人刚聊几天，提问者问对方怎么看婚姻和孩子，对方说“先相处看看，以后再聊”；之后仍正常聊天，没有明显矛盾或索款。提问者担心对方故意隐瞒，想知道目前能判断什么、怎样继续了解又不把猜测当事实。

**人际深度解析的答复**：

> 目前只能确认对方在简介里说自己喜欢徒步和做饭，也希望认真发展一段关系；还不能确定对方对婚姻和孩子的实际打算，更没有足够依据说对方在故意隐瞒。简介没写收入、婚史和是否想要孩子，这些只是尚未了解的信息；刚聊几天时说“先相处看看，以后再聊”，可能是希望慢些，也可能尚未想清楚。之后两人仍正常聊天，也没有明显矛盾或索款；目前还不足以据此认定对方在欺骗你。
>
> 你希望尽早确认是否合适，对方目前希望推迟讨论，两种节奏可能不一致。还需要弄清楚的是：“认真”对双方分别意味着什么，对方对婚姻和孩子有没有初步想法，以及什么时候愿意再谈。可以先说明自己的取向，建议下次深入聊天时交换大致想法，无需立即承诺。如果对方之后一直回避，或说法前后矛盾，再重新判断；即使没有欺骗，节奏不合也可以成为减少投入的理由。

### 3. 主管纠正我的错误，算不算霸凌？

**情境输入**：Caro 的报告确有一处数字错误。主管 Ray 私下指出错误，解释修正方法，并给她两天改好；没有提到当众羞辱或威胁。Caro 觉得被批评不公平，认为 Ray 在霸凌她。她问这种感受是否足以说明霸凌，还应该了解哪些情况。[Acas 的职场霸凌说明](https://www.acas.org.uk/bullying-at-work/if-you-think-youre-being-bullied)也区分了建设性的工作纠正与霸凌行为。

**互动风险分析的答复**：

> 觉得委屈值得认真看待，但这种感受本身还不足以说明 Ray 在霸凌你。现有材料中，报告确有数字错误；Ray 私下指出、解释修正方法，并给了两天期限，没有提到公开羞辱或威胁。按目前这些信息，更像是针对具体工作的纠正，还看不出足以认定霸凌的依据。主管想确保报告准确，你希望获得公平、尊重的反馈，这两项诉求可以同时成立。
>
> 还需要了解当时具体怎么说、语气如何，两天的期限是否合理、对所有人的标准是否一致，以及此前有没有持续贬低或排斥，或是在 Caro 提出异议后报复她。可以先核对错误和修改要求，说明完成修改需要哪些资源；再具体指出哪些表达让你不舒服。
>
> 若另有持续不当行为，可按日期记录具体事件，向可信同事或组织支持渠道了解情况，不必只围绕“这算不算霸凌”争论。

### 4. 网恋对象接连要钱，拒绝会不会太冷漠？

**情境输入**：交友软件认识三周，几乎每天聊天。对方说自己在国外工作，打算下个月来见面，但之前两次约视频都临时取消。先说母亲住院要交费用，几天后又说汽车坏了，再次要求汇款到海外账户。提问者还没转钱，觉得拒绝帮忙像是太冷漠，但这些理由也无法独立核实，于是问：“这算危险信号吗？哪些事能确认？我现在该怎么做？”类似情节见 [FTC 的网恋冒充者案例](https://consumer.ftc.gov/media/video-0119-online-romance-imposter-scams)。

**互动风险分析的答复**：

> 这些情况已经足以让你先停下，不要转钱；但还不能据此确认对方的身份或动机。你们认识三周，几乎每天聊天。对方说自己在国外工作、下个月会来见你，却两次临时取消视频；先说母亲住院要钱，几天后又说汽车坏了，再次要求你汇款到海外账户。困难也可能是真的，但两人越聊越亲近，你可能越难开口拒绝；钱的风险却落在你身上。
>
> 现在还不知道的是：对方的真实身份、这些困难是否属实、收款账户是谁的，以及对方能不能接受你的拒绝。你可以安排视频，再通过自己独立找到的雇主官方联系方式核实对方关于工作的说法。即使视频接通，也不能证明索款的理由是真的。
>
> 先不要转钱，也不要提供账户信息；这符合 [FTC 的防骗建议](https://consumer.ftc.gov/articles/what-know-about-romance-scams)。拒绝付款不等于冷漠；若继续催促，可停止联系并向交友平台反映。

### 5. 从认真交往到催我投资，中间发生了什么？

**情境输入**：第 1 天，交友软件认识的 Alex 说自己在西雅图做投资顾问；第 8 天表示想认真交往，让提问者改用 Telegram；第 15 天说手机坏了，不能视频，却开始介绍一个投资平台；第 17 天发来盈利截图，要求当晚转 5,000 美元并保密。提问者提出先核实公司，Alex 回答：“你连我都不信吗？”提问者问：哪些能确认？这是连续升级还是普通误会？现在该怎么做？FBI 对这类骗局的说明也提到关系建立、引导投资、虚假收益和提现受阻等环节。[FBI/IC3 案例说明](https://www.ic3.gov/PSA/2022/psa221003)

**互动风险分析的答复**：

> 先不要转这笔 5,000 美元。几天里，风险一步步升高：第 1 天以西雅图投资顾问身份建立可信感，第 8 天提出认真交往并转到 Telegram，第 15 天称手机坏了不能视频，却介绍投资平台，第 17 天用盈利截图催当晚付款、要求保密。面对核验，他说：“你连我都不信吗？”这把事实问题变成感情考验，压缩了核验时间和求助空间。
>
> 换平台或手机故障单独不能证明诈骗，但这些信号放在一起，足以让你先停下交易。对方的身份和任职情况、平台由谁运营、钱会转到哪里，都还没有核实；截图也不能证明盈利是真的。你可以从 [Investor.gov](https://www.investor.gov/introduction-investing/getting-started/working-investment-professional/investment-advisers) 查询注册信息，再用独立找到的公司联系方式确认是否本人；同名登记不排除冒名。
>
> 保留现有记录，找可信的人商量，不以小额转账测试，也无需继续联系才能退出。

## 为什么单独做成 Skill

这个想法最早来自我在职场里的观察，也来自朋友在生活中遇到、后来跟我聊起的事。同一件事里，每个人站的位置不一样，在意的东西也不一样。大家说出口的话，常常带着各自的立场和诉求；只听其中一句，很容易漏掉前面发生过什么，也容易把猜测当成事实。

我当时想做的，有点像人们说的“读空气”：从说的话和做的事往回看，各自想争取什么、担心什么，为什么会这样表达，哪些背景还没说出来。再把这些线索放回事情经过里，看看有没有更能解释现状的说法。这也包括回头看自己：我当时站在什么位置，我的表达又给别人带来了什么。

这不是读心。只凭几句话，没法确定别人真正的想法；新信息来了，之前的判断也可能要改。写成文章，可以讲明白这套看法；但碰到具体的聊天，读者还得自己想起该从哪里问。我把这套分析思路做成 Skill，是希望这组问题能用在一件件具体的事情里：看看谁在意什么、哪些话没有说透、自己的理解还漏了什么。有了新情况，也可以回来看看原来的判断还成不成立。

<h2 id="install-relation-forge">安装</h2>

| 你想处理的问题 | 安装哪个 Skill |
|---|---|
| 读征友介绍、理解聊天中的诉求、回看自己的行为 | 人际深度解析 `person-deep-analysis` |
| 梳理索款、投资邀约、关系施压，或疑似霸凌 | 互动风险分析 `interaction-risk-analysis` |

平时想读读聊天、回看自己的经历，可以先装“人际深度解析”。两个都需要的话，也可以一起装。

Codex 安装“人际深度解析”：

```sh
npx skills add Liyuk/relation-forge --skill person-deep-analysis -g -a codex -y
```

Codex 安装“互动风险分析”：

```sh
npx skills add Liyuk/relation-forge --skill interaction-risk-analysis -g -a codex -y
```

Claude Code 用户把命令里的 `-a codex` 换成 `-a claude-code` 就行。聊天材料仍由你使用的平台处理，并不会因为装了 Skill 就留在本地。它能分析的是你提供的内容，不能靠这些内容查明身份、认定犯罪或诊断人格。

## 找一件你想弄明白的事

不用把整份聊天记录都搬过来。挑出你在意的那几句，说说当时发生了什么、自己哪里想不通，就可以开始了。贴之前记得去掉姓名、账号和联系方式。

比如想回看自己的一次冲突：

```text
$person-deep-analysis
这是我和同事的一次冲突。我想知道我们各自在意什么，
我的哪句话可能让事情变得更难处理，以及下次可以怎么说。
[事情经过和有关的对话]
```

如果对方的要求让你不安：

```text
$interaction-risk-analysis
对方先提出这个要求，我拒绝后又发生了这些事。
请帮我看看压力是怎样增加的，以及哪些信息值得核实。
[按时间排列的有关片段]
```

读到和实际对不上的解释，可以直接指出来：“这里不是这样，前面还有一件事。”有了后续，也可以补上，看看原来的判断还成不成立。想先把事情弄明白，就先聊到这里；需要商量怎么回应，再往下问。

如果一段关系让你觉得不舒服，有些事情一直想不明白，或者你正在经历这样的事，可以把它带进来聊聊。从最困扰你的那一段说起，让 RelationForge 帮你理一理，看看自己遇到了什么。
