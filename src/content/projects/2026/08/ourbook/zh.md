> 一个由南开人发起、延续了十余年的公益项目:在校生与毕业生写下自己真实的大学体验,帮高考生填报志愿时看到更立体的大学。项目传承了七八年,内容一度托管在第三方平台;我 2018 年重构项目、把数据接管回来自建站,此后一路维护,最终收尾留档。这篇文章一半写这个项目本身,一半写它所在的行业——2011 到 2026 年,高考资讯从"信息稀缺"走到"AI 大模型",而 OurBook 始终站在市场的反面。

## 一个 2012 年开始的公益项目

2012 年 3 月的一个晚上,两位南开人在人大图书馆偶遇,聊起当年填志愿的草率。一句"希望填志愿的时候知道面对的是什么",开启了后来延续十几年的项目:组织南开毕业的学生,写下自己真实的大学体验——不是排名,不是录取线,是"在这所学校读一年之后,我发现它是这样的"。

到 2018 年,这个项目已经传承了七八年——**7 届南开校友、500 多人**接力投稿,从北大清华到各省高校,总字数超过百万。内容一直在流动,也一直有站点承载,**但托管在第三方建站平台上**(老站运行在快站 `lovenk.kuaizhan.com`)。

**2018 年 4 月,我们决定把项目重构,把数据接管回来自建。** 5 月 19 日,我建立了 GitHub 仓库 `weNKers/OurBook`,把第三方平台上的投稿整体迁移出来,用当时还很新的 VuePress 搭起自建站,www.wenkers.cn 就此上线。

## 我做了什么

那段时间的核心工作其实是两件事:**数据接管**和**自建站重构**:

- **数据接管**:大量投稿原本托管在第三方建站平台(快站),我写爬虫把几百篇文章整体抓下来,整理成按学校分目录的 Markdown,统一补上 frontmatter 元信息——项目的核心资产第一次回到自己手里。
- **站点重构**:用 VuePress 0.9 + 自定义主题重新搭建,按"地区 → 学校 → 文章"两级导航;`constants/univ.js` 维护缩写与中文全称的映射,侧边栏由脚本自动扫描生成。
- **搜索**:接入 Algolia 全文搜索,后因体积问题关闭 service worker,退回到基于标题和路径的多关键字模糊匹配。
- **评论与反馈**:从 Disqus(广告太多)换到 laibili,再换到自托管的 Cusdis——每一次都是"评论模块"这个组件库里的长期债。
- **部署**:GitHub Actions 发布 GitHub Pages + 自定义域名 CNAME。

一个很"老派"的静态站,却把几个问题解决得很彻底:文章是可读的 Markdown 文件,任何人打开仓库就能看到全部内容;站点是纯静态的,几乎零运维成本;内容属于社区,以 CC BY-NC-SA 4.0 开放。commit 历史里那句"隔了四年还能跑起来已经是奇迹了",是这类老项目共同的写照。

2022 年和 2026 年,我又两次把它现代化:升级 VuePress 2 + Vite,接入 SEO / sitemap 插件,把 Cusdis 评论的生命周期修到稳定,给仓库补上一整套内容审计脚本——检查本地资源、图片、内链、frontmatter,`npm run check` 一条命令跑完再上 CI。

## 2011-2026:高考资讯类产品的市场脉络

在写这个项目时,我顺带梳理了一遍它所在的市场。十五年里,同一个问题——"怎么让考生在填报志愿时看到真实的信息"——被完全不同的产品形态回答过。

### 2011-2014:信息稀缺时代

2011 年,一个考生家庭想了解一所大学,主要靠三样东西:纸质《报考指南》、班主任的经验、论坛里学长学姐的口口相传。教育部"阳光工程"早已建立了官方信息平台,提供招生政策与院校基本信息,但对"一所大学读起来到底是什么感觉"这类问题几乎是空白。

这正是 OurBook 缘起时的背景——2012 年那个晚上,两位南开人缺的恰恰是这种第一手的"主观体验"。而当年几乎没人把这件事当一门生意。

### 2014-2018:政策开启与算法创业潮

2014 年 9 月,国务院发布《关于深化考试招生制度改革的实施意见》:文理不分科、浙江上海试点、取消特长生加分。新高考从政策上把志愿填报变得空前复杂——选科、赋分、专业组,"填报"从一次选择变成了需要专业工具的决策。

一批创业公司踩在这个风口上涌现。优志愿是其中最典型的一家,用历史录取数据 + 算法做"冲稳保"志愿推荐,2016 年拿到千万级 A 轮融资;同赛道还有完美志愿等一批玩家。2017 年,浙江、上海率先举行新高考首考,艾媒发布了第一份《高考志愿填报专题研究报告》——行业第一次进入大众视野。

### 2018-2023:巨头入场、免费化与乱象

2019 年,夸克推出高考特别版,覆盖超 2600 所高校、1500 个专业——搜索引擎巨头第一次把高考做成一个完整的信息服务频道。此后几年夸克坚持"普惠免费",连续五年服务千万考生家庭,把志愿填报从付费咨询往免费信息的方向拉。

同一时间,咨询生意也在膨胀:2021 年新增志愿填报相关企业同比增长 77%,媒体开始用"千亿市场"形容这个赛道(这个数字争议不小)。乱象随之而来——高价咨询、"志愿规划师"证照乱象、饥饿营销。2022 年 6 月,教育部专门发文,严禁培训机构以志愿填报咨询服务谋利,严禁学校与机构合作。同年,张雪峰式的网红报考咨询开始爆火,2024 年媒体甚至报道其"3 小时卖课 2 亿"。

### 2023-2026:AI 接管与官方下场

2023 年起,AI 成了这个赛道的主角。夸克在 2025 年发布"首个高考志愿大模型",上线深度搜索、志愿报告、智能选志愿三大功能;百度 AI 志愿助手接入 DeepSeek;QQ 浏览器推出"AI 高考通"。

2024 年,教育部上线"阳光志愿"系统——官方第一次免费提供志愿填报信息系统,直接回应高价咨询。2026 年,全国高考报名人数达到 1290 万;也是这一年,央视曝光"志愿填报服务市场乱象":有家长花 8800 元买填志愿服务,换来 20 多页"AI 废话"。官方免费工具 + AI 生成内容,一边在抬高供给,一边也在暴露这个行业的投机。

## 公益内容与商业化产品的分野

把 OurBook 放在这十五年里看,它的位置很有意思——**它从第一天起就站在市场的反面**。

**当 2014 年后的创业公司忙着用"算法""数据"包装志愿填报时,OurBook 提供的是一个人亲手写下的主观体验。** 没有概率,没有冲稳保,只有"我在北大读了一年之后,发现它是这样的"。

**在信息形态上,它始终是"人"而不是"模型"。** 一篇 2012 年录入的北大综述,第一句是"我和你们中的很多人一样陶醉在她的传说中"。这种信息,算法算不出来,大模型也生成不了——它来自一个真实的人对一所大学的整体记忆,带着判断、情绪和偏见,而偏见恰恰也是真实的一部分。

**它还是免费的,而且是彻底的免费。** 从 2012 年至今,这个项目没有接过广告、没有卖过咨询、没有 VIP。CC BY-NC-SA 4.0 意味着任何人都可以自由复制与传播。在媒体所称的"千亿市场"里,这几乎是一种异类。

**但时间也在改变这件事本身。** 十五年过去,市场从纸质指南走到 AI 大模型,信息越来越"丰富"。一个考生想了解一所大学,现在有短视频、直播、各种 App、大模型问答——获取信息的渠道比 2012 年多了太多。**OurBook 因此不再具备当年的时效性**:一篇写于 2012 年录入的北大综述,讲的还是那个年代的北大;它帮助过的,是信息稀缺时代的一届届考生。

它没有被商业化成"产品"去续命,也再没有新的投稿在流动。**它定格在了那里,作为一段集体记忆被保存下来。**

## 尾声

写这篇文章时(2026 年 8 月),项目已经停止更新,作为一份留档被保存:66 所高校、400 余篇文章,站点仍然跑在 GitHub Pages 上,由 GitHub Actions 自动发布。它没有融资,没有团队,没有商业模式——有的只是一批曾经愿意把大学生活写下来的人。

而我的角色,是发起人之一,也是最后收尾的图书管理员:2018 年把这份集体记忆从第三方平台接管回来,之后一次次回来擦拭它的技术栈,直到它从"有用的信息"变成了"纪念一段时代的东西"。有些项目最后的归宿不是生长,而是被好好保存下来——这大概就是图书管理员和作者的区别。
