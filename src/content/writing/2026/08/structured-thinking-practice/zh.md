> 本文是[《五镜法：联系导向的问题定位》](/research/2026/08/connection-oriented-problem-location/)的实战篇——那篇讲这套方法"是什么、凭什么成立、边界在哪"，这篇只讲"怎么用"。工具的定义不在这里重复，用到的地方顺手带一句；想查完整定义，看研究版或文末速查卡。

先记住一句话：**结构化不是"有条理的样子"，而是把"结论、证据、假设、下一步"分开摆，让别人能指出他不同意的是哪一格。**

下面直接上四个场景。

## 面试：把"讲讲你的项目"从流水账变成结构

被问"讲讲你最有挑战的项目"，多数人答成流水账。先给结论，再用 STAR（情境—任务—行动—结果）展开：

- **结论**：我用风险排序把测试补到关键路径上，上线后事故减了一半。
- **情境**：接手一个要上线、但测试覆盖率只有 30% 的模块。
- **任务**：三个月内把覆盖率提到 80%，且不能延期。
- **行动**：先列风险清单（MECE，不重不漏），再按"高频×高风险"排优先级（2×2，两个维度正交切四格），先补关键路径。
- **结果**：上线后线上事故减半。

再用五镜里的两镜理解面试官：**立场镜**——他站在"招错人代价大"的位置；**利益镜**——他要判断"你能不能把这套方法复制到新环境"。所以讲"行动"时，重点不是"我多努力"，而是"我用什么可复用的方法"。

## 晋升：把"我很努力"换成"可复现的证据"

晋升材料最忌讳写成成绩流水账。先拆标准，再补证据，最后明说取舍：

- **拆标准（MECE）**：晋升标准拆成四块不重不漏——技术深度 / 业务影响 / 协作与带人 / 价值观。
- **找缺口（决策矩阵）**：给自己每块打分，找出最弱的一块，重点补证据。
- **结论先行**：材料开头一句话"我这一年把 X 指标从 a 提到 b，方法是……"。
- **取舍**：诚实写"我放弃了什么、为什么"。只会列成绩的人，反而像没有优先级。

用五镜理解评审：**立场镜**——评审怕"升错了人"；**利益镜**——他们要"可复现的证据"，不是"我很努力"。所以每一句都要落到可检验的事实，而不是形容词。

## 汇报：让上级听完就知道"要我做什么决定"

**场景**：你向上级汇报一个卡住的项目，讲了五分钟过程，对方问"所以呢？你要我做什么？"

**结构化（结论先行 + 状态—阻塞—决定—下一步）**：

- 结论：项目会延期两周，需要你定一件事——砍范围还是加人。
- 状态：核心功能完成 70%，卡在支付接口。
- 阻塞：支付接口依赖第三方，对方排期比预期晚一周。
- 决定：需要你拍板——砍掉一个非核心功能按原期上线，还是加一个人并行做。
- 下一步：你定了之后，我当天出调整后的排期。

**用五镜理解上级**：**立场镜**——上级站在"项目延期会不会影响我对外承诺"的位置；**利益镜**——他要的是"别把延期变成意外"。所以结论摆最前面，别让他从细节里自己找问题。

## 项目合作：把"谁拖累了谁"变成"底层是什么"

两个团队合作——A 做平台、B 做业务接入，延期后互相指责"A 该先出接口""B 该先给需求"。

先结构化：把"谁拖累了谁"换成事实表（各自交付节点、阻塞项、依赖），从"对人"变成"对事"。

再用五镜逐镜照一遍：

1. **因果镜**（5 Whys）：为什么延期？→ 接口没定 → 为什么？→ 两边字段口径不一致 → 为什么？→ 没有共同文档。

   ```mermaid
   flowchart TD
   A["Delay"] --> B["Interface undecided"] --> C["Field definitions misaligned"] --> D["No shared doc"]
   ```
2. **二元镜**：正方"A 该先出接口"，反方"B 该先给需求"，两面对立。
3. **辩证镜**：客观是两边都在等对方，没有 owner 定时间。
4. **立场镜**：A 要平台稳定，B 要业务上线快，目的都成立。
5. **利益镜**：真正原因是"谁先动谁吃亏"——先定的人要担返工风险。

底层找到了，方案才对准它：定一个 owner + 冻结接口时间 + 取舍（先支持 80% 场景，剩下的下一版）。这比"两边都再努力一点"有用得多。

## 速查卡

**五镜五问**

| 镜 | 问句 |
| --- | --- |
| 因果镜 | 为什么会发生？一层层问下去 |
| 二元镜 | 正反两面各是什么？ |
| 辩证镜 | 客观是怎样的？ |
| 立场镜 | 他的目的和需求是什么？ |
| 利益镜 | 真正的原因和谁的利益？ |

**到底了没有？** 换掉你现在的方案，问题还在不在？还在，就是没到底层。

**动手前四问**：结论是什么？依赖哪些事实？哪些假设没验证？对方看完该做什么？
