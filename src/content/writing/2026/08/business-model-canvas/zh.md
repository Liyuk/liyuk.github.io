企业投资课上讲了一个图：商业模式画布（Business Model Canvas）。它就是一张画布，九个格子各放一个要素。老师反复强调的那句话是——**九个格子不是九个可选项，而是同一台机器的九个部件；只有都转起来、互相咬合，这个项目才立得住。** 更准的说法是：**九个格子必须能互相解释、自圆其说；薄不等于缺（有些格子本就该轻，比如自助式 SaaS 把客户关系做轻是优点不是漏洞），但说不通的地方一定会漏。**（这是成熟期的终局状态；中途未必九格都齐，见下文"按阶段看"。）

先把九个格子记下来，留个底。每个格子附上它要回答的那个问题，和一句我自己的理解。

## 九个格子

1. **客户细分（Customer Segments）** —— 为谁创造价值？谁是最重要的客户？
   一句话：先想清楚"卖给谁"，别做"面向所有人"的生意。

2. **价值主张（Value Propositions）** —— 帮客户解决什么问题、满足什么需求？
   一句话：别人凭什么选你，而不是选别人或什么都不做。

3. **渠道通路（Channels）** —— 通过哪些渠道触达客户？哪个最有效、成本最低？
   一句话：怎么让客户知道你、买得到、用得顺。

4. **客户关系（Customer Relationships）** —— 想和客户保持什么关系？获取、维系、增购各怎么做？
   一句话：一次成交还是长期绑定，这是有成本的选择。

5. **收入来源（Revenue Streams）** —— 客户为什么愿意付钱？付多少、怎么付、各占多少？
   一句话：钱到底从哪几路进来，哪一路是主力。

6. **核心资源（Key Resources）** —— 兑现价值主张离不开哪些资源（人、钱、技术、资质、渠道）？
   一句话：没了它这事就做不成的那些东西。

7. **关键业务（Key Activities）** —— 必须做好哪些事，价值主张才能落地？
   一句话：你每天真正在忙、且不可外包的那几件事。

8. **重要伙伴（Key Partnerships）** —— 谁是关键伙伴和供应商？从他们那里拿到什么、由他们代做什么？
   一句话：哪些环节不自己做、靠别人，以及为什么。

9. **成本结构（Cost Structure）** —— 最重要的固有成本是什么？哪些资源或业务最烧钱？
   一句话：钱主要花在哪，是固定成本还是可变成本。

## 九个格子怎么连起来

画布中间是**价值主张（2）**，把左右两边接起来。它不是 3×3 方阵，而是**左右各四格、中间夹一格**：

| 内部 · 花钱（左 4 格） | 中间（1 格） | 客户 · 赚钱（右 4 格） |
|---|---|---|
| 重要伙伴（8） | **价值主张（2）** | 客户关系（4） |
| 关键业务（7） | | 渠道通路（3） |
| 核心资源（6） | | 客户细分（1） |
| 成本结构（9） | | 收入来源（5） |

- **右边是客户侧**：客户关系（4）、渠道通路（3）、客户细分（1）、收入来源（5）——回答"怎么赚到钱"。
- **左边是内部侧**：重要伙伴（8）、关键业务（7）、核心资源（6）、成本结构（9）——回答"怎么把事做成、钱花在哪"。

这个框架真正的用处不在"把九个格子填满"，而在检查**九个格子之间自不自洽**。几个我最常用来对照的点：

- 你选的客户（1），会不会真的被你的价值主张（2）打动；
- 收入来源（5）能不能长期盖过成本结构（9）；
- 关键业务（7）和核心资源（6）是不是真的在撑价值主张（2），还是各忙各的。

这也就是课上说的"只有这些条件都满足才能做好项目"：不是九个格子挨个打勾，而是九个格子连起来能自圆其说。画布能帮你看清"生意逻辑通不通"——有没有哪一格是空的、哪两格在打架；但"能不能投"取决于画布之外的东西（团队、市场、竞争、估值），画布是**必要但不充分**。

## 按阶段看：不是"九个格子都满"才成立

开头那句"互相咬合、自圆其说"，说的是**成熟期的终局状态**，不是对任何阶段的统一要求。每个阶段有它**必须回答清楚、且最可证伪的问题**；其余格子允许先只当假设放着，但要**诚实地当假设管**，不能当事实讲。所有格子都要持续盯——只是每阶段的主矛盾不同，不是"过了这阶段就没人看它"。

| 阶段 | 必须回答清楚的问题 | 判断 |
|---|---|---|
| 种子期（想法） | 客户细分 + 价值主张 | 你选的那群人，是不是真有那个痛（能否用低成本实验检验） |
| 验证期（PMF） | 价值主张 + 渠道 + 收入（雏形） | 有没有人愿意付钱，而不只是说好 |
| 扩张期（规模化） | 关键业务 + 核心资源 + 成本结构 | 放大时会不会亏、供应/履约撑不撑得住 |
| 成熟期（存量） | 客户关系 + 收入来源 + 成本结构 | 复购、留存、毛利、护城河还在不在 |

（转型期 / 第二曲线不是排在这之后的第 5 站，它往往在成熟期之前就要**并行或提前启动**；该问的是：旧的价值主张和核心资源能不能迁移，还是得从零来。）

所以投资判断落到画布上，就两件事：

1. 当前阶段该回答清楚的问题，证据给够了吗？
2. 还没验证的格子，是当"假设/风险"在管，还是当"已经成立"在讲？

第二条尤其致命——很多项目失败不是格子空，而是把假设讲成了事实。

## 商业模式原型与例子

同样一张画布，填出来的格子组合往往落在某一种**原型**上。原型 = 哪两个格子咬得最紧。认出原型，就知道该重点看哪几格。

| 原型 | 代表 | 咬得最紧的格子 |
|---|---|---|
| 多边平台 | 美团、Airbnb | 客户细分（多边）× 关键业务（匹配撮合） |
| 剃刀 + 刀片 | 吉列 | 客户关系（规格锁定）× 收入来源（耗材复购） |
| 免费增值 | Spotify | 成本结构（版权）× 收入来源（付费转化） |
| 注意力平台 | 抖音 | 价值主张（算法）× 收入来源（广告） |
| 开放生态 | 小米 | 硬件低毛利获客 × 生态/服务高毛利变现 |
| 长尾 | 亚马逊、淘宝 | 渠道/履约 × 海量 SKU |
| 高频带低频 | 美团外卖 → 酒店 | 高频刚需养用户 × 低频高毛利变现 |

拿美团填一遍九格，看"平台型"长什么样：

| 格子 | 美团 |
|---|---|
| 客户细分 | 消费者 + 本地商家 + 骑手（三方） |
| 价值主张 | 消费者：方便、快、选择多；商家：获客 + 履约；骑手：灵活收入 |
| 渠道通路 | App / 小程序 + 大规模地推 |
| 客户关系 | 自助下单 + 评价 + 会员 |
| 收入来源 | 商家佣金、广告、配送费、会员费 |
| 核心资源 | 平台网络效应、骑手履约网、地推、数据 |
| 关键业务 | 供需匹配、骑手调度、地推获客、履约 |
| 重要伙伴 | 商家、骑手/外包、支付、供应链 |
| 成本结构 | 骑手成本、地推人力、技术、补贴 |

美团的关键咬合是"收入（佣金）和成本（骑手）必须同步扩张，且各边用户互相增强"——飞轮转没转起来，就是它能不能投的核心。

## 变体与容易混淆的框架

商业模式画布有几个衍生版本，都是为不同目的改的：

| 变体 | 改了什么 | 用来干嘛 |
|---|---|---|
| 精益画布（Lean Canvas） | 四个换四个：重要伙伴→问题、关键业务→方案、核心资源→关键指标、客户关系→不公平优势 | 早期创业：这个想法会不会死 |
| 价值主张画布（Value Proposition Canvas） | 把"价值主张"和"客户细分"两格抽出来放大成两半 | 查"你给的"和"他要的"对不对上 |
| 商业模式环境（Business Model Environment） | 在画布之外**另画一张**外部环境图：市场力量、行业力量、关键趋势、宏观经济 | 看外部变化会砸到哪一格 |

另外有几个**名字相近、其实是另一套**的框架，容易混（我一开始就差点混）：

- **波特价值链（Value Chain）**：不是"左右各四、中间夹一"，而是一条横着的 5 节基本链（进货物流 → 生产经营 → 出货物流 → 市场营销 → 售后服务），上面盖 4 条支持（企业基础设施、人力资源管理、技术开发、采购）；它**没有"价值主张"这个词**。价值链自身也有一串变体（微笑曲线、价值商店/价值网络、共享价值等），另议。

  ```mermaid
  flowchart LR
  subgraph support
  SA["Firm infrastructure"]
  SB["HR management"]
  SC["Technology development"]
  SD["Procurement"]
  end
  subgraph primary
  A["Inbound logistics"] --> B["Operations"] --> C["Outbound logistics"] --> D["Marketing & sales"] --> E["After-sales service"]
  end
  ```
- **GE-麦肯锡九宫格 / 人才九宫格**：是 3×3 矩阵（行业吸引力 × 竞争地位；绩效 × 潜力），用来排序"选谁砍谁"，不描述生意怎么运转。
